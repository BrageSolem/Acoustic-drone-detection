# The Following codes

## XML label conversion

The training of the YOLO algorithm using the DroneDetectDataset is done by first converting the xml
label files by running the XML_conversion.py file which was generated by CLAUDE ai. This does as the name imply a conversion from the XML format to
txt files for YOLO. In the dataset present here the labels have already been converted. 

## YOLO training
The YOLO training is performed in the training.py file which was generated by CLAUDE ai. The file takes
the DroneDetectDataset file and trains a YOLO model for it.

## Onnx conversion
In order to convert the file to HEF for HAILO the YOLO model had to first be converted to ONNX, which is
performed in the onnxConversion.py file also generated by ClAUDE ai

## Tests
Several test files are present in the project. The testing.py file, generated by CLAUDE, runs the YOLO
model locally using the laptops webcam. 

The Video_tests.py file applies the YOLO model to muliple videos present in the Test_Videos directory, and saves the
results as a separate video in the Test_videos/results folder. 

## Where are the models

The final trained YOLO model can be found in the runs directory, with the final used model trained
being under the drone_xml_model_full/weights. 

## Dataset
This project uses the dataset from:

> Pawełczyk, M. Ł., & Wojtyra, M. (2020). Real World Object Detection Dataset for Quadcopter Unmanned Aerial Vehicle Detection. *IEEE Access*, *8*, 174394–174409. https://doi.org/10.1109/ACCESS.2020.3026192

Which can be downloaded from https://github.com/Maciullo/DroneDetectionDataset
